# Vibe Studio 手动测试手册（M2 完成版）

> 适用版本：`task/m2-target-model`（T001–T026 + U01 Layout v2，G0/G1/G2 通过）
> 环境：Windows 11 + Microsoft Edge + Node 24 / pnpm 11；DSH `0.2.1-rc.2`；开发 profile 仅 `vibe-dev`
> 全量走一遍约 20–30 分钟
> 覆盖范围：预览闭环（启动/帧率/视口/导航/刷新）、输入（点击/键盘/中文/滚动）、Console、Network、工具栏与生命周期、`.vibe` 设置。
> 检查 / 标注 / API 三个页签目前是占位页，只验证空状态。

## 1. 一次性准备

### 1.1 构建插件

在仓库根目录 `F:\Project\DSH_vibecode_studio`：

```cmd
cd /d F:\Project\DSH_vibecode_studio
pnpm install
pnpm build
```

判断成功：输出里出现 `built lib\index.js` 和 `built lib\client.js`。

> `pnpm install` 已装过可跳过；它装的是项目依赖到 `node_modules/`，pnpm 本体和共享缓存都在 F 盘全局位置，不会占用项目外的空间。

### 1.2 确认插件已链接进开发 profile

```cmd
F:\Deepseek-Harness\DH\bin\dsh.cmd --profile vibe-dev --dump-config | findstr vibe-studio
```

看到 `- id: vibe-studio` / `name: dsh-vibecode-studio` 即已就绪。若没有，执行一次：

```cmd
F:\Deepseek-Harness\DH\bin\dsh.cmd plugin --profile vibe-dev add link:F:/Project/DSH_vibecode_studio
```

> `dsh` 通常不在 PATH 上，必须用 `F:\Deepseek-Harness\DH\bin\dsh.cmd`（包装器会设置 `DSH_HOME`、`TEMP` 到 F 盘）。**不要**把包装进 `desktop` / `web` profile。

## 2. 启动流程

需要**两个窗口，都保持开着**。

### 窗口 1：被测页面（fixture）

```cmd
cd /d F:\Project\DSH_vibecode_studio
pnpm fixture:dev
```

成功标志：输出 `Local: http://127.0.0.1:4320/`，浏览器直接打开能看到 “Vibe Studio Fixture” 页面。这个窗口一关，预览页就白屏。

### 窗口 2：DSH

```cmd
F:\Deepseek-Harness\DH\bin\dsh.cmd --profile vibe-dev --no-open --host 127.0.0.1 --port 4317
```

成功标志：终端打印一行

```text
dsh web: http://127.0.0.1:4317/?token=<一串字符>
```

> **启动比较慢时看起来像没反应**：DSH 在完全就绪前不打印任何内容（激活插件、组装客户端都在静默进行）。等这行出现再操作，别重复开第二个实例。

### 打开 Studio

1. 复制上面带 token 的完整 URL，在浏览器打开。
2. 右侧边栏点 **新标签页** → 选 **Vibe Studio**。
3. 右栏出现标题 `Vibe Studio`，默认停在 **预览** 页签。

## 3. 详细使用流程

### 3.1 启动预览

1. 预览页地址行填 `http://127.0.0.1:4320`。
2. 点 **启动**。
3. 等待单行状态出现：

   ```text
   ● 运行中 · 30 fps
   ```

4. 点状态行可展开详情（模式 / 帧数 / 序号）；画布出现 fixture 页面，帧数持续增长。
5. 空状态会提示“输入本地地址（如 http://127.0.0.1:3000）后点启动”。

- 只接受 `http://localhost` 或 `http://127.0.0.1`（可在设置里加其它本机 origin）。
- 断流时状态行的详情（点击状态行）会从“流式”变成“轮询”，属正常自动降级。

### 3.2 操作页面（输入转发）

1. 先在画布内**点击**目标元素（如 `Name` 输入框），目标页获得焦点。
2. 键盘输入英文；切系统输入法输入中文；`Ctrl+V` 粘贴。
3. 滚轮滚动预览；`Tab` / `Esc` 按页面逻辑生效。
4. 点 **Add item** 等按钮，页面状态更新并反映到画面。

- 输入只作用于画布内目标页，不会影响 DSH 界面。
- 中文走隐藏 textarea + `insertText`；输入法失败会显示提示，可逐字输入或粘贴。

### 3.3 看控制台

1. 点底部常驻 tab **控制台 (N)** 展开；抽屉覆盖在画布下缘，不会改变画布尺寸。
2. 抽屉标题显示 `控制台 · N 个错误 · M 个警告`；用 **全部 / 错误 / 警告 / 信息** 过滤；点 **清空** 重置。
3. 再点同一 tab 或抽屉右上角关闭按钮收起；关闭后 tab 计数仍实时更新。
4. 触发页面报错后，新条目应立即出现，清空后序号继续增长。

### 3.4 看网络

1. 点底部常驻 tab **网络 (N)** 展开。
2. 抽屉标题显示 `网络 · N 个请求 · M 个失败`；发请求后条目出现：方法、URL、状态、结果（成功/失败）。
3. 点条目展开响应体（按需加载）；用 **全部 / 失败** 过滤；点 **清空**。
4. 大响应体会截断到 64 KiB 并标注；base64 内容按字节数标注。

### 3.5 工具栏

- **状态行**：`● 空闲 / 运行中 · N fps`；点它展开详情（模式 / 帧数 / 序号 / 最近错误）。
- **地址行**：输入 URL + **启动/前往**；**↻** 重新加载目标页。
- **⋯ 更多**：视口预设（含 **Fit panel** 适配当前面板）、**在浏览器打开**（仅本机 http(s)）、**停止**、失败的 **重启**、目标选择。
- 视口宽高输入不再常驻，改到 **设置 → 预览**。

### 3.6 异常与恢复

- 预览 Edge 被关闭/崩溃：约 1 秒内状态变 **失败**，画布出现失败卡片（原因 + 3 条检查项：开发服务器/端口/Edge），只有 **重启 / 停止**，**不会自动重连**。
- 点 **重启**（卡片内或 **更多** 菜单）：重新拉起预览，旧进程不残留。
- 内部切到 检查/标注/API 页签再切回：会话保留，帧数继续增长。
- 关闭 Vibe Studio 标签页：会话停止。

### 3.7 设置

1. 打开 **设置** 页签，等待表单加载。
2. 修改字段后点 **保存**；保存成功显示“已保存”，仓库根生成 `.vibe/studio.json`（已 gitignore）。
3. 展开 **预览** 分组（懒加载），填宽高后点 **应用到预览**：只改目标页视口，不改 DSH 窗口；预览未运行时会提示先启动。
4. 重启 DSH 后设置仍在；删掉该文件即回默认值。

### 3.8 布局（Layout v2）

窗口高度保持 900px，把右栏拖到 320 / 400 / 500px 三档分别看：

1. 没有横向滚动条（地址行不被截断、状态行不换行）。
2. 常驻行只有 3 行：状态、地址、底部 tab；视口宽高输入不在预览页。
3. 画布区域（舞台）占面板高度 60% 以上；16:9 位图在其中居中，320px 宽时位图约 304×171（左右留黑边是等比缩放的正常结果）。
4. 打开/关闭控制台、网络抽屉，画布尺寸不变化；抽屉覆盖在画布下缘。

> 设置作用于 Host 与面板共享的同一份文档；非法值不会写入。

## 6. 正常但容易误判的现象

- **启动慢且无输出**：DSH 就绪前不打印，等 token URL 出现即可。
- **流式变轮询**：断流自动降级，能恢复就正常。
- **帧率偏低**：预览被遮挡时 Chromium 会节流页面动画/计时器；把窗口置前再测。
- **停止耗时**：Desktop 载体实测约 4.9 s，接近 5 s 上限；超过 5 s 或无进程残留要记录。
- **中文输入**：只能验证系统输入法；CDP 模拟不代表真实输入法。
- **多目标**：目前只注册 `web` 目标，多目标独立会话未实现（后续任务）。
- **截图**：截图能力存在，但产物存储/截图 UI 未接入（后续任务）。
- **“在浏览器打开”** 会离开应用，本手册只验证按钮与提示。

## 7. 故障排查

| 现象 | 检查 |
|---|---|
| `dsh` 不是内部或外部命令 | 用绝对路径 `F:\Deepseek-Harness\DH\bin\dsh.cmd` |
| 启动后无任何输出 | 等待；确认没开第二个实例；确认端口未被占用 |
| 状态一直“空闲”/启动失败 | fixture 窗口是否开着；地址是否 127.0.0.1/localhost；Edge 是否安装 |
| 预览黑屏但状态运行中 | 看 Console 抽屉；直接用浏览器打开目标 URL 自查 |
| 输入无反应 | 先点画布内元素；目标页是否获得焦点 |
| Console/Network 一直为空 | 是否已产生事件；抽屉是否打开；可调 `logLevel: debug` 后重启 |
| 设置保存失败 | 字段范围；`.vibe/studio.json` 是否被手改坏（可删除重开） |
| 改了代码没生效 | 重新 `pnpm build` 并重启 DSH、刷新页面 |
