# 手动测试手册 — Vibe Studio（M2 完成版）

> 适用版本：`task/m2-target-model` @ `ebee1e5`（T001–T026，G0/G1/G2 均通过）
> 环境：Windows 11 + Edge + Node 24 / pnpm 11；DSH `0.2.1-rc.2`；开发 profile 仅 `vibe-dev`
> 预计用时：15–20 分钟
> 本手册只覆盖**已实现**的功能：预览闭环、输入（含中文）、Console/Network 抽屉、工具栏与生命周期、`.vibe` 设置。检查/标注/API 三个页签目前是占位页，只需确认空状态正常。

## 0. 准备

在仓库根目录执行：

```bash
pnpm install     # 已装过可跳过，幂等
pnpm build
```

`dsh` 通常不全局在 PATH 上，用 DSH 安装目录里的包装器（本机为
`F:\Deepseek-Harness\DH\bin\dsh.cmd`，它会把 `DSH_HOME`、`TEMP`、npm 缓存指到 F 盘）。
首次或重新链接插件时：

```cmd
F:\Deepseek-Harness\DH\bin\dsh.cmd plugin --profile vibe-dev add link:F:/Project/DSH_vibecode_studio
```

本机 `vibe-dev` profile 已链接该包，可跳过上面的 `add`。

启动一个被测页面（两种任选）：

```bash
# A. 仓库自带 fixture（推荐，含计数器/表单/失败请求/console 报错）
pnpm fixture:dev          # http://127.0.0.1:4320

# B. 你自己的本地 Web 应用（必须是 http(s)，且 host 为 localhost / 127.0.0.1）
```

启动 DSH：

```cmd
F:\Deepseek-Harness\DH\bin\dsh.cmd --profile vibe-dev --no-open --host 127.0.0.1 --port 4317
```

浏览器打开 DSH 打印的带 token 地址 → 右栏点 **新标签页** → 选 **Vibe Studio**。

> 安全提示：不要把这个包装进 `desktop` / `web` profile；预览只允许本机地址。

## 2. 预览启动与视口（P1）

| # | 步骤 | 预期 |
|---|---|---|
| P1 | 预览页地址框填 `http://127.0.0.1:4320`，点 **启动** | 数秒内状态变为 `状态: 运行中 · 流式 · 帧数: N · #seq · 30 fps`，画面出现 fixture |
| P1 | 看状态行 10 秒 | 帧数持续增长；增量 ≥100（≥10 fps）视为达标（本机实测约 25 fps） |
| P1 | 视口宽度填 `1280`、高度 `800`，点 **应用** | 画面比例变化，页面内 `innerWidth/innerHeight` 为 1280×800（可在 fixture 控制台看） |
| P1 | 视口填 `10` 或 `99999`，点 **应用** | 提示“宽度和高度需在 64–7680 之间”，不生效 |
| P1 | 地址改为 `file:///C:/` 或 `https://example.com`，点 **前往** | 拒绝并提示只接受本地预览地址；不会导航 |
| P1 | 点 **刷新** | 页面重新加载，帧数继续增长 |
| P1 | 点 **在浏览器打开** | 只在系统浏览器打开本机地址；非本机地址给出 `只有本机 http(s) 预览…` 提示 |

> 判断帧率的小技巧：记录 10 秒内“帧数”字段的差值，差值/10 即 fps。流式断流时会自动回退到“轮询”，属正常降级。

## 3. 输入转发（P2）

先在 fixture 页面滚到表单区域可见。

| # | 步骤 | 预期 |
|---|---|---|
| P2 | 在预览里点 `Name` 输入框 | 目标页该输入框获得焦点（出现光标） |
| P2 | 键盘输入 `hello` | 输入框出现 `hello`，无丢字/错位；点击到画面反馈 <200 ms |
| P2 | 点 `Note`，用系统中文输入法输入 `你好，世界` | 输入框显示完整中文；抽屉 Network 里**没有**拼音中间态请求 |
| P2 | 点 **Add item** | 列表新增一条 `hello — 你好，世界` |
| P2 | 在预览里滚动滚轮 | 目标页滚动，画面跟随；不会滚动 DSH 外层页面 |
| P2 | 按 `Tab` / `Esc` | 焦点按页面顺序移动 / 页面行为符合预期 |
| P2 | 把输入法切换成不可用状态（可选） | 出现“输入法文本未能发送…”提示；恢复后可直接继续输入，或 `Ctrl+V` 粘贴 |

## 5. Network 抽屉（P4）

| # | 步骤 | 预期 |
|---|---|---|
| P4 | 点 fixture 的 **POST /api/echo** | 网络摘要请求数 +1；条目方法 POST、状态 200、结果“成功” |
| P4 | 点 **GET /api/boom** | 新条目状态 500、结果“失败”；摘要失败数 +1 |
| P4 | 展开 200 条目 → 响应体 | 懒加载显示 `{ hello: 世界 }` 类 JSON 文本；头部先脱敏 |
| P4 | 过滤 **失败** | 只剩 500 条目；切回“全部” |
| P4 | 快速连点多次 | 条目按 id 原位更新（pending → 成功/失败），不重复刷屏 |
| P4 | 点 **清空** | 列表清空，Host 同步清空（重开抽屉仍为空） |

> 大响应体会截断到 64 KiB 并标注“响应体已截断”；base64 内容按字节数标注——属预期。

## 6. 生命周期与清理（P5）

| # | 步骤 | 预期 |
|---|---|---|
| P5 | 运行中点 **停止** | 状态回到 `空闲`；预览 Edge 进程退出（≤5 s） |
| P5 | 打开任务管理器（或 PowerShell 查 `msedge` 且命令行含 `playwright_chromiumdev_profile`） | 无残留预览进程 |
| P5 | 再次 **启动** | 可正常重启，帧数从新会话开始 |
| P5 | 运行中手动结束预览 Edge（任务管理器结束该 msedge 进程树） | 约 1 s 内状态变 `失败`，出现“预览已断开”+ **重启 / 停止**；**不会自动重连** |
| P5 | 点 **重启** | 恢复预览；旧进程不残留 |
| P5 | 运行中切到 检查/标注 页签再切回 | 预览会话保留，帧数持续增长（内部切 tab 不停） |
| P5 | 关闭 Vibe Studio 标签页 / 收起右栏直到卸载 | 预览会话停止，无孤儿进程 |

PowerShell 检查命令（只读）：

```powershell
Get-CimInstance Win32_Process -Filter "Name='msedge.exe'" |
  Where-Object { $_.CommandLine -like '*playwright_chromiumdev_profile*' } |
  Select-Object ProcessId, CommandLine
```

## 8. 边界与已知限制（不算缺陷）

- **多目标**：目前只注册 `web` 目标；多目标独立会话未实现（FR-PRE-09 待后续任务）。
- **截图 UI**：截图能力存在但尚未接入产物存储/界面（FR-PRE-07 后续任务）。
- **“在浏览器打开”** 会离开应用，本手册只验证按钮可用，不强制点击。
- **Desktop 预览被遮挡时** Chromium 会节流页面动画/计时器，帧率可能偏低；把预览窗口置于前台即可。
- **停止耗时**：Desktop 载体实测 ~4.9 s，接近 5 s 上限；若明显超 5 s 请记录。
- **系统级中文输入法**只能在真机手测；CDP 模拟 IME 不代表真实输入法。

## 9. 故障排查

| 现象 | 先检查 |
|---|---|
| 启动即失败 / 状态 `不可用` | 本机是否安装 Edge；地址是否为 `http(s)://localhost` 或 `127.0.0.1`；端口是否被占用 |
| 画面黑屏但状态运行中 | 目标页是否白屏/报错；看 Console 抽屉；换 `pnpm fixture:dev` 复测 |
| 帧率 <10 fps | 是否流式；预览是否被遮挡；机器负载；目标页是否在持续动画 |
| 输入无反应 | 是否先点击了预览画布；目标页是否获得焦点；中文是否走的系统输入法 |
| Console/Network 一直空 | 目标页是否产生事件；抽屉是否已打开；Host 日志 `logLevel: debug` |
| 设置保存失败 | 是否违反字段范围；`.vibe/studio.json` 是否被手工改坏（可删除后重启） |
| 卡在旧版本 | 改代码后需 `pnpm build` 并重启 DSH（host 会热重载包，但 client 需刷新页面） |
